Productivity Garden
The more you linger, the less focus points you get... Get back to work!
Features: 
- Leave the tab and you earn points
- Allows you to be more productive
- Growing a garden to encourage more productivity :)
- Progress is tracked in local storage

## How to play 
1. Leave the tab (which saves a timestamp)
2. When you return the points get added
3. And you can grow a garden!
